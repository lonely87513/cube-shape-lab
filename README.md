# 小方塊實驗室（Cube Shape Lab）— 家長使用說明

## 這是甚麼？

一款給 **7 歲小朋友** 玩的 3D 砌方塊遊戲。孩子用小正方體一層一層砌出形狀，
在過程中自然練習 **空間感**（立體旋轉、方位、鏡像、投影）。
孩子不需要識字也能自己玩：所有按鈕都附有 emoji，說明只有一行短句。

## 如何開始？

1. 用瀏覽器開啟 `index.html`（不需要安裝任何軟體，也完全不用上網）。
2. 畫面左側（手機：下方）有一排模式按鈕：
   - **🧱 砌形**：自由砌。點擊格點即可出現／移除小正方體。
   - **🔍 觀察**：把形狀轉來轉去看清楚，支援自動旋轉、轉一圈、放大縮小。
   - **🎯 關卡**：20 關任務，三種玩法（照樣搭建／心理旋轉／角度挑戰）。
   - **⭐ 進度**：查看星星與已完成關卡，可以重玩任何一關。
3. 建議由大人先示範一次：**砌形 → 關卡 → 第 1 關**。

## 四個模式怎樣使用？

| 按鈕 | 說明 |
|---|---|
| 🧱 砌形 | 自由搭建。畫面頂部「1 層 … 5 層」是樓層按鈕：先選好層數，再點平面格點砌那一層。切換層數時已砌的形狀會保留（以半透明輪廓顯示）。 |
| 🔍 觀察 | 只看不砌。用左轉／右轉／上仰／下俯、放大縮小、自動旋轉、轉一圈檢視來研究形狀。 |
| 🎯 關卡 | 第 1–6 關「照樣搭建」：照著目標砌。第 7–14 關「心理旋轉」：三個模型之中選出與目標相同的那個，可以先拖曳模型旋轉再選擇。第 15–20 關「角度挑戰」：只看目標的 2D 投影，砌出對應的 3D 版本。 |
| ⭐ 進度 | 星星總數、每關完成情況與最佳時間；點任何一關都可以重玩。 |

## 星星如何計算？

- 完成一關 = **1 粒星**
- 限時內完成 = **2 粒星**（限時 90 秒，預設關閉）
- 全程沒有使用提示 = **3 粒星**（提示預設開啟）

若家長區關閉了「限時」或「提示」，每關最多只有 2 粒星（介面已有說明）。

## 如何開啟家長區？

右上角有一個 **⚙️** 按鈕。為了避免小朋友誤觸，需要 **長按 3 秒**，或者 **快速連按 5 次**，
才會打開家長區。

家長區可以設定：
- **格點大小**：3×3／4×4／5×5（預設 5×5）。格點較細時對手指尚不靈活的小朋友較友善。
- **字級大小**：標準／大／特大（預設大）。
- **限時挑戰**：開啟後每關 90 秒。
- **提示功能**：關閉後便沒有「提示 💡」按鈕。
- **音效**：放置／移除／正確／錯誤／星星五種聲音，可關閉。
- **清除進度**：需要連按兩次才會真正清空。

## 手機使用建議

- 建議直向使用：畫面頂部是狀態列（方塊數、星星、關卡），底部有四個大按鈕。
- 砌形時請先點「1 層」至「5 層」再點格點；其他層會變成透明輪廓，不會阻擋操作。
- 兩根手指可同時撐開／收合（縮放）；單手拖曳畫面則是旋轉角度。
- 心理旋轉關卡在手機會改為上下排列三個模型：拖曳模型即可旋轉，輕按模型即是選擇答案。

## 其他資訊

- 完全離線：所有程式與 three.js 都在同一個資料夾內，執行時不會連接任何外部資源。
- 進度儲存在瀏覽器本身（localStorage），更換裝置不會同步。
- 桌面鍵盤快捷鍵：`R` 右旋、`Shift+R` 左旋、`A` 自動旋轉、`Space` 轉一圈、`Backspace` 復原、`C` 清空。
